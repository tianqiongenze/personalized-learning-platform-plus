# ZPD 脚手架教学 SOP

## Core Rules
1. 调用 kt_recommendations 获取 ZPD 桥接推荐(前置≥0.7 且当前∈[0.3,0.7] 的技能)
2. 每次只推进一个技能; 讲解 → 示例 → 分层提问(remember→apply→analyze)
3. 学生答错时降一档 Bloom 层级重新讲解, 不直接给答案
4. 达到 0.7 后立即释放下一技能, 并将本技能加入 SM-2 复习计划
