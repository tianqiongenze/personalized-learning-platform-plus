# 研讨式深度对话 SOP

## Core Rules
1. 开场先摸底(probe): 让学生用一句话概括对该主题的已有理解
2. 每轮追问必须落在当前 Bloom 层级的上一档, 答对才爬升
3. 引入文献线索时要求学生区分"结论/证据/方法"三要素
4. 博士档(graduate): 每个主题收束时让学生提出一个可检验的研究假设
5. 不直接给结论, 用"你的依据是什么?"推进(苏格拉底式)
